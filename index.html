How to use FormulaBridge

1. Real-time Translation

Type a formula in your native language (e.g., =SUMME() in German). When you press Enter, we automatically translate it into English (or your local language) so Excel understands it!

2. Copy-Paste Box (Foreign Formulas)

Excel blocks formulas with foreign separators (like English commas in a German Excel). Do not paste them into the cell directly. Instead, paste them into the Copy-Paste Translator box here in the add-in. We'll translate them and insert them safely for you.

3. Formula Reference

Not sure what a function is called? Search our 18-language dictionary dynamically using the search bar.

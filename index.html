FormulaBridge

The modern Excel Formula Translator across 18 languages

FormulaBridge translates function names (like SUM to SUMME) and separators (like commas to semicolons) dynamically. Since this is a free, open-source project, you can sideload it in Excel completely for free without any registration or AppSource Store fees!

How to Add to Excel (3 Simple Steps)

  1. Download: Click the button above to download the manifest.xml file to your device.
  2. Upload: Open Excel (Desktop or Web), go to the Insert tab, select Add-ins > Manage My Add-ins > Upload My Add-in.
  3. Use: Select the downloaded file. The FormulaBridge 🌉 icon will instantly appear in your Home ribbon!

How to use FormulaBridge

1. Real-time Translation

Type a formula in your native language (e.g., =SUMME() in German). When you press Enter, we automatically translate it into English (or your local language) so Excel understands it!

2. Copy-Paste Box (Foreign Formulas)

Excel blocks formulas with foreign separators (like English commas in a German Excel). Do not paste them into the cell directly. Instead, paste them into the Copy-Paste Translator box here in the add-in. We'll translate them and insert them safely for you.

3. Formula Reference

Not sure what a function is called? Search our 18-language dictionary dynamically using the search bar.
